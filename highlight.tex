\section*{Highlights}
\begin{itemize}
\item Plane-strain thermal stress in BaTiO$_3$ needs the full 3D elastic contraction
\item The simplified reduction reverses the piezoelectric-thermal voltage polarity
\item An analytical interior solution and a second discretization check the FE model
\item Fixing all root derivatives changes the open-circuit voltage by about 0.1\%
\end{itemize}
